📖 REPORTS KAISE PARHEIN
Kahan se reports milengi?
1. Upar wale box se har file ka 👁 PREVIEW / ⬇ DOWNLOAD button.
2. Direct: GitHub repo → file → Download raw file. Bot logs: Colab output (ya repo → Actions).

File decoder:
• state.json — bot ka live dimagh: updated = last run, engine = AI ya bot, timeframes = har TF ka signal/score/entry/SL/TP/path, candles = matrix ka fuel.
• perf.json — model improvement: har model ki resolved accuracy (acc), pichli run se delta (delta_pct), samples (n). system = overall ensemble accuracy.
• ledger.jsonl — append-only record (P4); har line = ek run ka proof.

Kab fikar karein? state STALE (bot band), perf.json absent, ya system accuracy lagatar girti rahe.
