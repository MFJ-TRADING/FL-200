📖 GUIDE — REPORTS KAISE PARHEIN
Kahan se reports milengi?
1. Isi tab mein upar wale box se PREVIEW / DOWNLOAD button dabayen.
2. Ya GitHub repo MFJ-TRADING/FL-200-Private → folder reports/ (ya root) → file par click → Download raw file.
3. Bot ke run logs ke liye: repo → Actions tab → latest workflow run → run-bot → console logs.

File decoder:
• state.json — bot ka current live dimagh: last run time, mode, har symbol ka signal/plan, pillar score. Yeh sab se important hai.
• backtest_report.json — backtest ki poori report. Parhne ka tareeqa:
  - return_pct = total profit % · max_drawdown_pct = sab se bara ghrata (−ve acha)
  - sharpe = profit per unit risk (>1 acha, >2 bohat acha)
  - profit_factor = profit ÷ loss (>1.3 acha)
  - win_rate_pct + avg_r — R matlab risk ka multiple (+2R = 2x risk kamaya)
• trades.csv — har trade ki entry/exit, reason, R-multiple. exit_reason dekhein: TP1/TP2 = win path, SL = loss, TIME_STOP = timeout.
• equity_curve.csv / equity_curve.png — account value ka graph. Smooth upar jata hua = healthy.
• predictions.csv — har candle par Grid/Chronos/Quant ke scores (model diagnostics).
• ledger.jsonl — append-only record (P4). Har line ek event; hash-chain integrity ke liye.

Kab fikar karein? Data STALE ho (bot run nahi hua), pillar score gire, ya equity curve neeche jaye — tab Actions/logs check karein.
🏛️ PILLAR LAW — 10 COMMANDMENTS
P1 DATA INTEGRITY — fresh+valid data, weekend freeze. Bad data = HOLD. P2 ANALYZE — read own record + lessons before voting. P3 SELF-IMPROVE — conf-bias from own WR (clamped ±10, min 6 samples). P4 PERSIST — append-only hash-chained ledger. NOTHING deletable. P5 COMPARE — old vs new WR delta; "improving?" ka measured jawab. P6 LESSON LIFECYCLE — proposed→implemented→verified; max 12 active. P7 RISK ENFORCE — prop rules LLM ke baad bhi hard gate. P8 SIMULATE→DECIDE→TAG — form gate + reproducibility tag. P9 SECURITY — secrets sirf Secrets mein; weekly audit; owner-only. P10 HEALTH & DRIFT — feed fresh, error streaks, regime-shift flags. Conflict order: SECURITY > RISK > DATA > LEARNING > PERFORMANCE
